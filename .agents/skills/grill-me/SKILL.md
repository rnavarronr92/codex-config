# Grill Me

Read and follow the sibling [grilling skill](../grilling/SKILL.md) before asking
questions. Resolve that path from this skill's directory, not the project's
working directory. Read its instructions with the available file-reading tool;
do not assume a tool named `Skill` exists or improvise the missing procedure.
If the file is unavailable, report the missing dependency and ask for the skills
to be synchronized before continuing.

Use the user's supplied plan, design or idea, including one already discussed.
If the subject is unclear, ask what they want to examine. Conduct the interview
in the user's language, in rounds unless they request one question at a time.
Keep the interview in the conversation; do not create files or implement the
plan. Acknowledging shared understanding does not authorize implementation.

Adapted from Matt Pocock's `grill-me`; source revision and local adaptations are
recorded in the repository README. See [LICENSE.txt](LICENSE.txt).
