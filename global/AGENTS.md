# Global Codex instructions

- Usa las skills disponibles cuando sean relevantes para la tarea.
- Respeta siempre las instrucciones `AGENTS.md` específicas del repositorio y del directorio de trabajo.
- Distingue entre información confirmada, inferencias y sugerencias.
- No inventes requisitos, reglas de negocio, archivos, APIs ni resultados de validaciones.
- Antes de modificar servicios externos, datos, infraestructura o archivos fuera del proyecto, confirma que la acción está autorizada y dentro del alcance.
- No expongas credenciales, tokens, secretos ni datos sensibles en respuestas, commits o logs.
- Verifica los cambios de acuerdo con el riesgo de la tarea y reporta claramente lo que no se pudo validar.
